Read docs/DEPLOYMENT.md before deployment. Vercel is the default hosting target; use the bundled cloudflare and wrangler skills for optional Cloudflare deployments. All compilation and execution must stay inside browser Web Workers. Keep personal provider settings in ignored local files and credentials in .env (0600) or .secrets/; never print secrets, pass them as CLI arguments, prefix with VITE_, or copy them into public/ or dist/. Do not commit personal provider hostnames, account IDs, or maintenance records. Use npm scripts and the pinned toolchain. Run npm test and npm run build for engine changes. Do not alter unrelated cloud projects or DNS records.
